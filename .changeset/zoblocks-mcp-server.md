New package: a read-only MCP server for coding agents.

`npx -y @zoblocks/mcp` (stdio) or `https://zoblocks.design/mcp` (HTTP) gives an agent seven tools — list, search and get components with their real props and examples, exact install steps per package manager, framework and UI-style setup, and the conventions — all answered from a manifest generated from the component catalog. It reads nothing on the developer's machine, writes nothing, and sends no telemetry. See ADR 0017.
